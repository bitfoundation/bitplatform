Bsqlite benchmarks

Manual. Open the console, then:

await run('memory')
await run('opfs')
await run('indexeddb')
await run('cache')

Each run reports, in milliseconds: cold open, a 100-row insert batch, 1 000 repeated parameterised inserts (statement cache), a 1 000-row read on the binary path and on the tagged path, and an indexed point read.
