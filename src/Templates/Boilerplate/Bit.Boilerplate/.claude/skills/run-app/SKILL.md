---
name: run-app
description: Starts this project's app and uses it the way a user would, to see a change working. It waits until the app is ready, signs in with the seeded account, drives the web app with the Playwright MCP tools and the Windows and Android apps through their WebView's remote debugging, reads the browser console and the server's logs, finds the emails the app sends, and stops it cleanly. Use when the user asks to run, start or launch the app, to try, see or screenshot a change in it, or to check it on the Windows or Android app, when another skill needs the running app, or says "run app".
